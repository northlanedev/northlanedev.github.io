Бот заявок и записи

Задача
Клиенты пишут в разное время, заявки теряются в переписке, а запись ведётся вручную.
Решение
Бот проводит клиента по анкете, понимает «завтра 15:30» и не даёт занять уже занятое время.
Результат
Менеджер сразу получает карточку заявки со статусами и выгрузку в Excel.
Python, aiogram 3, SQLite, 31 тестКод на GitHub

Магазин в Telegram

Задача
Заказы приходят в личку вперемешку, а маркетплейсы забирают комиссию.
Решение
Каталог, корзина, самовывоз или доставка с порогом бесплатной доставки, статусы для покупателя.
Результат
Заказы приходят владельцу готовыми, с кнопками статусов и подсчётом выручки.
Python, aiogram 3, SQLite, 13 тестовКод на GitHub

Антиспам для групп

Задача
Спам-боты заходят в чат и рассылают рекламу быстрее, чем админы успевают удалять.
Решение
Капча новичкам, мьют за флуд, удаление ссылок от новых участников, предупреждения.
Результат
Чат чистый, а у админов остаются команды /mute 30m, /warn, /ban.
Python, aiogram 3, 23 тестаКод на GitHub

Мониторинг цен

Задача
Цены конкурентов меняются каждый день, а сверять их вручную долго.
Решение
Парсер обходит каталог, хранит историю цен и находит изменения.
Результат
Утром в Telegram приходит отчёт «подешевело / подорожало», плюс таблица Excel.

Крипто-алерты

Задача
Нужно знать, когда монета пересекает уровень, не сидя весь день в терминале.
Решение
Команда /alert btc > 70000, разовые и повторяющиеся алерты, работа в группах.
Результат
Уведомление приходит вовремя, а все цены берутся одним запросом с кэшем, без упора в лимиты API.
Python, aiogram 3, CoinGecko API, 19 тестовКод на GitHub

Как работаем

От первого сообщения до готового бота — 2–4 дня

Техническое задание писать не нужно: мы зададим вопросы сами.

  1. Вы описываете задачу

    Пара предложений в сообщении. Можно голосом.

  2. Мы присылаем план и цену

    Что будет делать бот, сколько стоит, когда будет готово.

  3. Делаем и показываем

    Вы проверяете тестового бота в своём Telegram.

  4. Запускаем

    Ставим на ваш сервер или передаём код с инструкцией.

Опишите задачу — ответим с планом и ценой

Если похожий проект уже есть в портфолио, начнём с него, и выйдет быстрее и дешевле.
